# 📦 Inventory Management System – Automation Framework

## 🚀 Overview

This project is a **Selenium + Java automation framework** for testing an Inventory Management System.
It covers end-to-end flows for **Login, Product, and Order modules** with clean execution logs and validations.

---

## 🛠️ Tech Stack

* Java
* Selenium WebDriver
* TestNG
* Maven
* Page Object Model (POM)

---

## 📂 Project Structure

```
src/main/java/
│
├── base/        # Base test setup (driver initialization)
├── factory/     # Driver Factory
├── pages/       # Page Object classes (Login, Product, Order)
├── utils/       # Utilities (Wait, Logger, etc.)
│
src/test/java/
└── tests/       # Test classes
src/test/resources/
└── config.properties     # Configutation properties
```

---

## ▶️ How to Run

```bash
mvn clean test
```

---

## 📊 Test Reports

After execution, reports are automatically generated by the **Maven Surefire Plugin**.

### 📁 Default Location:

```
target/surefire-reports/
```

### 📄 Generated Reports:

* Login Tests Report
* Product Tests Report
* Order Tests Report
* emailable-report.html (summary report)

### 💻 Example Local Paths:

```
target/surefire-reports/Inventory Automation Suite/Login Tests.html
target/surefire-reports/Inventory Automation Suite/Product Tests.html
target/surefire-reports/Inventory Automation Suite/Order Tests.html
target/surefire-reports/emailable-report.html
```
